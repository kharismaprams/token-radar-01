Token Radar — the best token launch radar: 198 pre-token protocols ranked by implied value, with a farm plan for each. Model radar-2 scores every protocol from the snapshot's own figures — TVL, seven-day growth, age with no token on record, and chain count — and the dashboard lets a reader search, filter, sort, open any protocol's detail view, and re-rank the board live in a model sandbox.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
